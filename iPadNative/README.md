# TouchBridge 纯 iPad 实验版 0.1

这是可安装的原生实验应用，用于验证 iPad 能否直接接收 TouchBridge v12 主控的触控，并经自身开发服务执行。被控端不用运行电脑转发程序。首版仅支持同一无线局域网，尚未验证真实设备上的输入接受情况、20–30 ms 延迟或长期游戏后台运行。

## 你现在怎么测试

1. 在 iPad 安装 [LocalDevVPN](https://apps.apple.com/app/localdevvpn/id6755608044)。允许它添加 VPN 配置，并开启连接。保留默认本机隧道配置；本应用使用 `10.7.0.1`。如果商店地区不可用，请先反馈，不需要安装不明来源替代品。
2. 用你此前安装 IPA 的签名工具（例如 Sideloadly）签名安装 `TouchBridge-iPad实验版-0.1-unsigned.ipa`。IPA 未签名，不能直接点开安装。签名/初次信任是一次准备，运行时不需要被控端电脑。保留 iPad 的开发者模式。
3. 将**这台 iPad**已有的完整配对记录存入 iPad“文件”，然后在 TouchBridge iPad 中点“导入这台 iPad 的配对文件”。记录含设备控制私钥，只在自己的设备间传递，不要发给别人。本应用保存到受保护的本地目录并排除备份，不上传记录。
4. 确认 LocalDevVPN 仍已连接，关闭其他镜像/自动化工具。在本应用选择和屏幕截图对应的方向，保留“同时建立屏幕会话”，点“启动 iPad 接收”。首次本地网络提示需要允许。
5. 出现“监听…:8798”后，点“复制连接码到主控”。电脑运行本目录的 `TouchBridge-无线HIDv12.exe`，选择主控，粘贴连接码连接。电脑和 iPad 要在能互相访问的同一 Wi-Fi 网络。新启动应用或 Wi-Fi 地址改变后重新复制连接码。
6. 刷新一张画面，先在安全位置测试一次按住、拖动、松开，观察 iPad 是否立即跟随。随后在分屏保留本应用做连续测试，再尝试切到游戏做短时测试。不要仅凭主控的“发送成功”认定实际生效。
7. 把以下结果告诉我：启动停在哪一步、是否有实际触控、按住时长是否同步、是否出现 Automation Running、主控显示的按下/松开延迟、切到游戏多久后断开。应用的“复制诊断信息”不包含配对私钥或连接码。

## 当前边界

- 应用不运行 XCTest/WDA，设计上避开 XCTest 的 Automation Running 来源；其他屏幕会话提示是否出现需要实测。
- 普通 iPad 应用无法保证切换游戏后长期常驻。这里使用系统允许的短时后台任务，剩余时间少于 10 秒时主动停止并尝试释放触控。系统挂起、杀进程、网络故障仍可能中止清理；首次测试请在安全界面进行。返回应用可以重启连接。分屏可用于验证，不等于所有游戏都支持分屏。
- 本地 HID 服务在部分系统版本上要求同时维持屏幕会话。若屏幕会话阶段失败，可以关闭该选项重新启动以检查 HID 连通性，但成功发包依然不能证明触控已被接受。
- 自身开发服务需要有效配对、开发者模式和匹配系统的开发者磁盘镜像（DDI）。首版不下载/挂载 DDI；你此前电脑端无线 HID 的准备可能已挂载，但设备重启后可能需要再次准备。`CoreDevice…check DDI` 就是这一步没有就绪。以后纯 iPad 首次初始化需要补上 DDI 挂载流程。
- 目前不是跨城市方案。LocalDevVPN 与另一款个人 VPN 同时运行的兼容性未解决；不依赖 Tailscale，不建立公网转发。
- 局域网协议有随机挑战 HMAC 认证，每次创建接收器生成随机连接密钥；传输本身不加密，只用于可信网络测试。连接码相当于控制凭证。
- 同时仅一个主控、一个触点。移动/释放按序处理；主控每 0.5 秒续期，连续 3 秒未续期就尝试释放。过期/其他手势消息拒绝执行；不重放不确定的按下。
- 触控和截图在不同队列及 TCP 连接中执行。触控持续时间由主控按下/松开决定，没有固定 20 ms 等待。`send_ms` 测的是调用耗时，不是画面响应延迟；主控 RTT 包含往返网络和排队，也不能承诺实际响应 20–30 ms。

## 实现与构建

SwiftUI / Network / CryptoKit 接收局域网命令；Rust 静态库通过 MIT 许可的 [idevice](https://github.com/jkcoxson/idevice/tree/3854a5df4a5a6dee71ffce4d8befc2ea356a8065) 使用 Lockdown → CoreDeviceProxy → 软件 TCP 隧道 → HID。屏幕授权流仅在设备内被接收并丢弃，截图另用 DVT 服务压缩后交给主控。

不使用越狱、不复制 StikDebug 的 AGPL 代码、不包含个人配对记录、签名证书或设备截图。第三方许可位于应用内 `ThirdPartyNotices.txt`。

GitHub Actions 在 macOS / Xcode 16.4 上运行 Rust 测试、编译 arm64 iPad 静态库、编译 Swift 应用并打包未签名 IPA。最低部署版本 iPadOS 17.4，当前目标实测设备为 iPadOS 26.3.1。云端编译通过并不代表真实 HID 权限和后台能力通过。
